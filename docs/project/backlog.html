Generated — do not hand-edit this page or its CSV. The source of truth is each story's own frontmatter in docs/stories/ (its folder = its stage: Plan → Build → Test → PR → Deploy → Archived). Change a story, then run node scripts/pm/generate-dashboard.mjs to refresh metrics/backlog.csv and this view.
Depends On (depends_on: in the story's frontmatter) = stories this one needs first. Depended By = stories that need this one — computed as the exact inverse, never authored. Only Depends On can block: a pending story is Blocked when any story it depends on has not reached Deploy or Archived, and Ready when they all have. Dependency chips are clickable — they jump to the linked story (switch to "All stories" to land on shipped ones).
